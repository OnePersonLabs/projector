# Validation results

This page records checks actually run on the delivered Markdown pack. It is not a Projector implementation test, model evaluation, or proof of complete semantic preservation.

## Automated checks

- Every one of the 38 input files has a source-map entry and disposition.
- Every generated Markdown page is reachable from the front-door index.
- All local Markdown link targets and the addressed local fragments were checked.
- No original conversation role headings or old sandbox-link dependencies remain in the pack.
- No exact repeated paragraph of 35 or more whitespace-delimited words was found. Short navigation/status boilerplate and intentional high-level orientation can repeat.
- All 136 original annotated bibliography identifiers resolve through 120 canonical primary-reference records.
- ZIP members were checked for integrity after packaging.

External research URLs are preserved as citations and were not all fetched or checked for availability. Current official Codex references were checked separately for the routing proposal. Local-link validity does not establish external-source accuracy.

## Editorial checks

The [distinction checks](DISTINCTIONS.md) compare consequential design choices against source passages. They preserve conditions, rejected alternatives, uncertainty, and the separation between archived design and the new routing proposal.

No independent second model, exhaustive claim-by-claim audit, or measured fidelity benchmark was run. The source-to-destination map is an accounting aid, not proof of complete conceptual coverage.

## Output shape

The pack has 40 Markdown files: a short root index, canonical concept leaves, a coupled experiment, a decision frontier, a separate routing proposal and archive workflow, research synthesis, a deeper annotated catalogue, and an optional audit layer.

The original 38-file archive remains unchanged and is not duplicated inside the output ZIP. No user repository, installed Codex configuration, or persistent Library file was modified.
