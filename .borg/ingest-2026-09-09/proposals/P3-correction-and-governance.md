# P3 -- Exercise a scoped correction through existing owners

Proposed. Implementation owner: wrap-up Task 7B. The host performs diagnosis; no general classifier, incident queue or autonomous policy service is added.

## What and why

Use a real failure from the runner, application adapter, existing validator or context reuse to prove the entire investigate/propose/correct/verify loop. Repair the responsible implementation, oracle, tool, context or accepted architectural decision. A local bug can end with a local repair. New governance requires a concrete reason to generalize.

## Stories

- A save-failure control exposes an optimistic UI message. Preserve the failed observation, repair the responsible persistence/UI contract, and retest success and failure without redesigning all storage.
- A tool cannot start the browser. Fix setup and preserve behavior as unknown; do not call the application broken or erase a previous valid failure.
- A proposed reuse rule incorrectly rejects an intentional variant. Use the counterexample to narrow or retire that rule through existing authority; repeated generated conformity does not outweigh it.
- A contributor's otherwise useful patch has one defect. Repair and revalidate its affected behavior while retaining independently current work.

## Design

Existing observation/result types distinguish operational failure, staleness, missing evidence and failed assertions. Reuse them, adding a missing evidence reference or actionable route only when the exercised case demonstrates a gap. Host reasoning may suggest causes and discriminating checks. A causal explanation remains a hypothesis until evidence supports it.

Existing coverage/impact issues, concerns, decisions, authorities and consequence products own applicable corrections. A code or oracle repair does not automatically create architectural products. New reusable enforcement needs a material recurrence mechanism or concrete safety invariant, scoped counterexamples and maintenance justification. Apply repository approval rules for any new broad guard; do not manufacture that work to complete this proposal.
