# P4 -- Verify the next change and record its real cost

Proposed acceptance method. Implementation owner: wrap-up Tasks 10.8--10.9 and 12.3--12.5. No trajectory-runner product, mandatory three-repository study or live-model economics gate is included.

## What and why

A first successful patch does not prove later work can recover intent or preserve behavior. Exercise one meaningful Projector self-change and a subsequent affected change in fresh sessions, including deliberately stale knowledge. Record actual setup, retrieval, validation, repair and semantic-maintenance costs. The final source-absent trial must execute changes, not merely answer design questions.

## Stories

- A later runner change preserves the earlier cancellation/recovery contract. The new behavior and the old obligation are verified separately.
- A validator/profile changes without a new Git commit. Reused evidence becomes stale; unrelated documentation does not falsely invalidate everything.
- The conceptual model makes a later change slower than ordinary code search would have been. Report observed overhead and simplify its actual cause. Do not assume future savings or claim comparative advantage from an unpaired run.
- A shorter implementation drops a negated condition. Behavioral failure overrides a favorable size/complexity metric.

## Design

Use existing acceptance/testkit, temporary repositories, saved contexts and bounded receipt/report fields. Add narrow mechanics only when a real test requires them. Keep evaluator-only perturbations or later requirements outside the implementing session until reveal. Use genuinely independent source/oracle review for precision-sensitive meaning. Deterministic fixtures verify mechanics; the real Projector change verifies practical use.

Functional self-hosting is required. Comparative economic superiority is a separate question. A later optional comparison uses matched snapshots, equally capable tools/notes/subagents, equal information at each reveal, each arm's accumulated state, all failed attempts and complete observed costs. Missing pricing/labor is unavailable, not zero. Existing accepted self-hosted-value meaning retains that comparison as an explicit unproved commitment; this plan does not silently declare it satisfied or require new paid trials.

No causal conclusion follows merely because an LLM names a root cause or a static metric correlates with failure. Use a targeted replay/intervention when it would change a decision, otherwise retain the hypothesis. Broad research and ablations are outside the critical path.
