# Demonstrate cumulative value on Projector itself

Demonstrate useful, cumulative project understanding on Projector itself and a bounded Psychord reconstruction rehearsal. Compare the delivered normal workflow with competent OpenSpec implementation and independent review using the same curated facts, model, tools, tasks and allowance. Build fresh isolated implementations without legacy Psychord code, carry each implementation forward, and reset agent context before coupled follow-on changes. Hold out evaluation cases and expected consequences, not required material facts.

The rehearsal exercises player-owned input, immutable recognition evidence, narrowly scoped skill evidence, optional musical offers, preview origin, interrupted recognition, restart and overlapping replay. System-generated events never become player evidence. Add a consumer after planning and verify scoped stale-dependency detection. Keep uncertainty in records whose origin cannot be established. This does not establish retained musical learning, acoustic output or hardware performance.

Measure correctness, missed obligations, false objections, repairs, context reconstruction, review questions, token use and elapsed time, including project setup and maintenance. Independent reviewer effort is a proxy for human burden. Recommend Projector for the rebuild only when critical obligations hold and there is a clear net advantage at acceptable cost. A tie, unresolved critical failure or cosmetic improvement favors OpenSpec.

Exercise project-aware reasoning on an actual candidate diff with concrete counterexamples. Retain demonstrated learning as the lightest useful scenario, relation, selector or transformation. Evaluate substantial mechanism contenders against an observed bottleneck; do not dismiss ambition or import speculative infrastructure by default. Keep failed and unavailable attempts visible. Use one initial paired three-checkpoint rehearsal and repeat affected cases after repair; expand only for decision-changing uncertainty. Tests and hashes establish their observed properties, not universal superiority.
