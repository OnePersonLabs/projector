The five biggest discoveries were:

- **Canonical state isn't actually closed under rebuild.** Accepted concepts, authored relations, standalone rules, and authority records need durable canonical representation.
- **Semantic backdating can be unsound.** A semantic hash needs an assurance level; heuristic equality cannot be allowed to prune downstream work.
- **The clean oracle is not independent.** It catches incremental/cache bugs, but shared analyzer/hash bugs can fool both paths.
- **Governance can become self-referential.** Lens membership → rules → projections → new membership needs stratification, SCC handling, and explicit convergence semantics.
- **Projector can manufacture evidence for itself.** Files normalized by Lens X must not later count as independent evidence that Lens X was the right architectural choice.

That last one was the most interesting third-order failure mode: without causal provenance, successful governance gradually turns into circular authority.

I also found an outright implementation-level problem: the normative code references roughly two dozen interfaces/types that the spec never defines, and its stated package dependency chain conflicts with the architecture in which the engine invokes runtime/analyzer implementations.
