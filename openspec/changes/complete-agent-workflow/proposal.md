## Why

- Support candidate-only synchronization without archive.
- Replace the technical root README with a short user journey and progressively disclosed documentation.
- Refresh and qualify the user-local installed plugin.

Plugin skills, host tools, managed lifecycle, initialization, user documentation and installed-client verification.
