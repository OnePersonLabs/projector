# Projector consumer guidance

Use Projector only while this project's `.projector/active` file exists. Check the marker before Projector work, including after a disable request in the same session. A nested Git repository needs its own activation. In an inactive project, carry out the user's request through the native host without Projector records or helpers.

The user describes ordinary work. Select the relevant skill yourself: `$opl-projector:recover-meaning` for unfamiliar meaning or interrupted work, `$opl-projector:carry-out-directive` for implementation, and `$opl-projector:reconcile-and-learn` for changed evidence or useful lessons. Use `$opl-projector:enable-projector` for an explicit enable, disable, or activation-status request. Do not make the user remember this routing or runtime commands.

Use authoritative meaning directly when it helps the work. The plugin is optional. Concepts hold conditions and reasons. Typed Relations connect meaning. Projection Units bind selected implementations to meaning. Pattern Candidates record reusable approaches and counterexamples. Projection Lenses select participants and collect scoped evidence.

Use native execution and delegation. The native root owns shared meaning and the checkpoint. Assign workers disjoint writes. Projector helpers do not schedule agents or execute a second workflow.

In an activated Git project, use reviewable local commits by default, subject to the user's and repository's commit rules. The native root owns staging and commits. Use the commit procedure in `$opl-projector:carry-out-directive`; the user does not need to request each commit. Pushes and history changes need separate authorization.

Recover only the meaning needed for the directive. Summaries point to authority; they do not replace reasons, exceptions, or reopening assumptions. State the scope of each supported claim. Keep unavailable evidence unresolved.

After work changes meaning or creates a useful future action, update the affected meaning or checkpoint. Routine work does not require a Projector ceremony. Preserve a mismatch before changing code, selection, checks, or meaning to resolve it.

See [the reference guide](references/guide.md) when YAML, helper requests, provider setup, or repair is needed. Use the selected skill for its workflow.
